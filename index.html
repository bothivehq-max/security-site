Rask “package”-idé

Start med en “Vuln Check” for å få oversikt, og gå videre til full pentest på de viktigste systemene.

  • Vuln Check (1–3 dager): skanning + validering + tiltaksliste
  • Web Pentest: OWASP-topprisiko + business-logikk
  • Internal / AD: misconfig, privilege paths, hardening
  • Retest: verifisering etter fiks

(Du kan endre navn/priser senere — dette er for å få siden live raskt.)

Tjenester

Fokus: konkrete funn + prioriterte tiltak

Web Application Pentest

Testing av innlogging, tilgangsstyring, input-validering, business-logikk og OWASP-risiko.

  • Manuell testing + verifisering
  • PoC der relevant
  • Prioritert remediations

Vulnerability Assessment

Rask oversikt over sårbarheter og feilkonfigurasjoner med anbefalte tiltak.

  • Skanning + validering
  • Risiko (CVSS / business-impact)
  • “Quick wins” først

Internal / AD Security Review

Sjekk av nettverk, privilegier, GPO, hardening og typiske angrepsstier i Windows-miljø.

  • Misconfig & privilege review
  • Hardening-baseline
  • Logging/audit anbefalinger
